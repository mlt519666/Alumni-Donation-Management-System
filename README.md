# 校友捐赠管理系统


## 项目简介

本项目旨在为高校打造一个高效、透明的校友捐赠信息化平台。系统不仅解决了传统手工记录捐赠数据易出错、难追溯的问题，更通过完善的数据库完整性约束与关系模型，保障了捐赠资金从“申请 -> 项目管理 -> 分配 -> 受益人”的全生命周期追踪。

## 系统核心功能

系统主要分为两个用户角色：**校友**与**捐赠理事**。

*   **校友端**：
    *   **捐赠申请**：提交一次性或周期性捐赠，指定资金用途（资助个人或资助项目）。
    *   **记录查询**：实时查询自己的捐赠记录及资金使用状态。
    *   **个人信息管理**：维护个人基本档案。
*   **捐赠理事端**：
    *   **捐赠使用管理**：创建、编辑、删除捐赠项目，分配受益单位或个人。
    *   **捐赠分配**：根据需求将资金分配给指定项目或受益人，并记录分配详情。
    *   **全局信息管理**：查看管理所有校友、受益人与项目的流转记录。


## 数据库设计亮点

本项目的重头戏在于严谨的数据库架构设计。从概念模型到物理落地，严格落实了**三范式**与**完整性约束**。

### 1. 实体与属性定义
共抽象出 6 大核心实体：
*   **校友**：校友编号、姓名、性别、工作职务、单位、电话、入学年份、院系、班级。
*   **捐赠理事**：理事编号、姓名、性别、电话号码。
*   **捐赠项目**：项目编号、项目名称、所需金额、开始时间。
*   **捐赠受益人**：受益人编号、姓名、性别、身份、电话。
*   **捐赠分配**：分配编号、分配金额、分配时间。
*   **User_**：userID、role（校友/理事/测试）、userName、userPassword。

### 2. 关系模型（E-R 转关系模式）
严格处理了 **M:N（多对多）** 与 **1:N（一对多）** 关系，避免了数据冗余：
*   **1:N 关系**：一名理事接受多名校友捐赠；一名理事负责多个分配。
*   **M:N 关系（拆解为中间表）**：
    *   *分配关系表*：关联「捐赠项目」与「捐赠分配」。
    *   *资助关系表*：关联「捐赠受益人」与「捐赠分配」。
    *   *管理关系表*：关联「捐赠理事」与「捐赠项目/受益人」。

### 3. 参照完整性与约束设计
在 SQL Server 落地时，设计了严密的约束机制：
*   **主键约束**：确保每条记录（如校友编号、分配编号）唯一非空。
*   **外键约束**：全面建立表间级联引用（如捐赠表通过外键关联理事表），防止出现孤儿数据。
*   **用户自定义约束**：如性别字段只能输入 `'男'` 或 `'女'`；捐赠类型仅限于 `'一次性捐赠'` 或 `'周期性捐赠'`。
*   **数据类型规范**：字符统一规划长度。


## 技术栈

*   **数据库环境**：SQL Server 2012
*   **后端与交互**：Java、JSP、Servlet
*   **Web 容器**：Apache Tomcat
*   **前端技术**：HTML/CSS/基础 JavaScript
*   **设计工具**：Draw.io (用于绘制 E-R 图与数据流图)

## 运行指南

1.  **数据库初始化**：
    *   在 SQL Server 中新建数据库`校友捐赠管理系统`。
    *   执行"校友捐赠管理系统.sql"完成所有表与约束的创建。
2.  **后端配置**：
    *   导入 Java Web 项目至IDEA。
    *   修改数据库连接配置文件（如 `properties`），填入你自己的 SQL Server 账号密码。
3.  **启动服务**：
    *   将项目部署至 Tomcat，启动服务器。
    *   浏览器访问 `http://localhost:8080/` 即可进入系统。
